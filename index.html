✅ QC & Alignment

Quality Control

FastQC
Essential

Quality control tool for high throughput sequence data

Website GitHub
fastqc sample_R1.fastq.gz sample_R2.fastq.gz -o qc/
MultiQC
Aggregation

Aggregate QC results from multiple tools into one report

multiqc qc/ -o multiqc/
Trimmomatic
Trimming

Flexible trimmer for Illumina sequence data

trimmomatic PE R1.fq.gz R2.fq.gz \ out1_paired out1_unpaired \ out2_paired out2_unpaired \ ILLUMINACLIP:adapters.fa:2:30:10
fastp
All-in-One

Ultra-fast all-in-one FASTQ preprocessor

fastp -i R1.fq.gz -I R2.fq.gz \ -o out1.fq.gz -O out2.fq.gz

Alignment

STAR
Recommended

Spliced Transcripts Alignment to a Reference

STAR --genomeDir index/ \ --readFilesIn R1.fq.gz R2.fq.gz \ --readFilesCommand zcat \ --outFileNamePrefix sample_
HISAT2
Alternative

Fast and sensitive alignment program

hisat2 -x genome -1 R1.fq.gz -2 R2.fq.gz \ -S output.sam
SAMtools
Post-processing

Utilities for manipulating alignments in SAM/BAM format

samtools sort input.bam -o sorted.bam samtools index sorted.bam
RSeQC
QC

RNA-seq quality control package

read_distribution.py -i sorted.bam \ -r genes.bed

📊 Quantification

featureCounts
Recommended

Fast and efficient read counting program

featureCounts -a genes.gtf -o counts.txt \ -p -B -C *.bam
HTSeq
Classic

Python framework for high-throughput sequencing analysis

htseq-count -f bam -r pos \ sorted.bam genes.gtf > counts.txt
Salmon
Alignment-free

Wicked-fast transcript quantification from RNA-seq

salmon quant -i index -l A \ -1 R1.fq.gz -2 R2.fq.gz \ -o quant_output
Kallisto
Pseudoalign

Near-optimal probabilistic RNA-seq quantification

kallisto quant -i index.idx \ -o output R1.fq.gz R2.fq.gz
RSEM
Isoform

Accurate transcript quantification from RNA-seq

rsem-calculate-expression \ --paired-end R1.fq.gz R2.fq.gz \ reference output
tximport
R Package

Import transcript-level quantification to gene-level

library(tximport) txi <- tximport(files, type="salmon", tx2gene=tx2gene)

🔬 Differential Expression with DESeq2

DESeq2 Workflow
Essential

Standard differential expression analysis in R

library(DESeq2) # Create DESeq dataset dds <- DESeqDataSetFromMatrix( countData = counts, colData = metadata, design = ~ condition ) # Run DESeq2 dds <- DESeq(dds) res <- results(dds) # Filter significant genes sig <- subset(res, padj < 0.05)
Visualization
Analysis

Common plots for RNA-seq results

# MA plot plotMA(res) # PCA plot plotPCA(vst(dds), intgroup="condition") # Volcano plot library(EnhancedVolcano) EnhancedVolcano(res, x='log2FoldChange', y='padj')
